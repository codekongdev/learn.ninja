A match brick has three to five pairs. The right column is shuffled; link each left item to its partner.

## When to use it

- Words and meanings, terms and definitions, symbols and names.
- Set `leftLang` or `rightLang` when a column is in another language, so browsers and screen readers treat it as that language.

## Fields

| Field | Required | Description |
| --- | --- | --- |
| `pairs` | yes | 3–5 pairs, each with `left` and `right` |
| `leftLang`, `rightLang` | no | Language of a column, for language lessons |
