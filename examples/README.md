# Example lessons

The seven test lessons, as JSON files that follow spec v0.4: button hierarchy, writing a PRD, compound interest, Spanish greetings, and map vs forEach (all beginner), plus correlation vs causation (intermediate) and the Bronze Age collapse (advanced). Used as test fixtures, in Storybook, in the docs demos and e2e tests, and at `/lessons/{slug}` in the web app. The skill doesn't ship them.
