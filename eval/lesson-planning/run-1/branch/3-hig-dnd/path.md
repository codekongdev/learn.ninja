# Drag and drop, the Apple HIG way

Source: https://developer.apple.com/design/human-interface-guidelines/drag-and-drop

Order: first what a drop should *do* (move, copy, undo), then how to show it while dragging, then how the destination takes it in, then the extras that only matter once the basics work.

| 2 | Feedback during a drag | Drag image after ~3 points, show which destinations accept, and show failed drops | not made yet |
