# Balanced

The default: teach a little, practise it right away, repeat. Each concept brick is followed by 2–4 question bricks that practise it from different angles, so the lesson is roughly one part reading to two parts doing.

## Concepts

One idea each, with a concrete example or a visual, as the teaching guide describes.

## Questions

- 2–4 after each concept. Each one asks something new about the concept: recognise it, apply it, spot it in a realistic case. The level file says how demanding they are.
- Pick each brick by fit (the teaching guide's table). Repeating a type is fine.

## Challenge

One harder, applied question that combines the concepts.

Every example in `examples/` is a balanced lesson.

## You've drifted if…

- The questions after a concept all ask the same thing in different formats.
- A concept brick has no question that uses it.
